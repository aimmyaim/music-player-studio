# Music Player Studio 8.1

A customizable, browser-based music player and overlay designer for video edits.

## Open the app

Once GitHub Pages is enabled, the public app URL will be:

https://aimmyaim.github.io/music-player-studio/

## Enable GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Choose **main** as the branch and **/(root)** as the folder.
4. Click **Save**. GitHub will publish the site at the URL above.

The repository is public, so the source code is also publicly viewable.

## Export notes

MP4 and MOV conversion loads FFmpeg packages from unpkg, so an internet connection is needed for those formats. WebM export does not use the FFmpeg conversion step.
